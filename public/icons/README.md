# PWA Icons

Drop these two PNGs in this folder before deploy. Until they exist the manifest will 404 those icon entries (the app still runs).

- `icon-192.png` — 192×192, transparent or solid `#0a7c4a` background, the AIDa "A" mark
- `icon-512.png` — 512×512, same artwork

Quick way to generate: run any rasterizer over a 1024×1024 source SVG, or use https://realfavicongenerator.net.
